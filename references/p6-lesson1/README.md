# P6 Lesson 1 gameplay references

These portrait browser captures come from the playable [greenhouse lesson](../../p6-lesson1.html) at 430 × 932 CSS pixels. During capture, test checkpoints moved between objects and advanced through handwriting handovers so the same run could cover all six missions and reach the final test.

| Gameplay moment | Standard to carry into other lessons |
| --- | --- |
| [Prelude](01-prelude.webp) | Centre the illustration and show progress in the lower left. The same treatment works for the epilogue. |
| [Task and controls](02-task-hud.webp) | Keep the task, replay control, and notebook up top, the joystick in the lower left, and the story helper in the lower right. |
| [Story helper](03-story-helper.webp) | Explain what happened, why it matters, and what the player should investigate. Use a device or character that fits the story. |
| [Object close-up](04-object-clue.webp) | Make the clue readable at phone size and connect the text to the object the player found. |
| [Comprehension check](05-comprehension.webp) | Ask about the clue or the word in context. Allow the player to revisit the clue and retry. |
| [Mission dictation](06-dictation.webp) | Show the sentence with a blank, a replay control, progress markers and one active handwriting box. |
| [Vocabulary notebook](07-notebook.webp) | Show discovery progress, with pinyin, the Chinese definition, an example sentence, audio replay and writing practice in each discovered row. |
| [Final test](08-final-test.webp) | Use the sentence bank and one box at a time. Keep the final test separate from mission dictation. |

The greenhouse predates the current language rule. Follow [AGENTS.md](../../AGENTS.md) for player-facing language when implementing these patterns in new lessons.
