# Moonbridge artwork

ImageGen artwork for this lesson uses the approved Moonbridge comic as its visual reference.

| Files | Use |
| --- | --- |
| `prelude-*.webp`, `ending.webp`, `cover.webp` | Chinese comic, epilogue, title, and distant scenery |
| `radio.webp` | Radio dock icon with a transparent background |
| `materials/radio-{front,side,back}.webp` | Generated orthographic views mapped to the faces of the in-world radio |
| Other `materials/*.webp` | Generated surface artwork for depot woodwork and roof, bridge and cliffs, vegetation, waterfalls, carts, lanterns, banners and paper |

Texture sheets and radio views are cropped and exported as WebP for use in the game. The 3D meshes define the shape and placement of the painted surfaces.

The fieldwork close-ups `lookout.webp`, `archive.webp`, `workshop.webp`, and `dispatch.webp` came from a new ImageGen sheet using the third prelude panel as reference. Each quadrant was cropped and exported at 540 × 540 pixels. The archive and dispatch illustrations also appear on their in-world signs.
